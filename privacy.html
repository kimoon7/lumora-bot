LUMORA Sales Bot · 시행일 2026-10-09

1. 대상

LUMORA Sales Bot(이하 "봇")은 LUMORA 직원과 경영진만 사용하는 내부용 텔레그램 봇입니다.

2. 처리하는 정보

  • 지정된 회사 단톡방의 메시지(번역 목적), 봇과의 1:1 대화
  • 직원이 제출한 일일보고, 회의록, 음성 메시지, 사진
  • 텔레그램 사용자 ID와 이름

3. 이용 목적

팀 내 번역, 업무 보고 정리와 저장, 업무 알림에만 사용합니다. 광고, 판매, 외부 제공에 사용하지 않습니다.

4. Google 사용자 데이터

봇은 회사 대표의 Google 계정에서 봇이 직접 만든 파일(보고서 구글 시트, 회의 사진 폴더)에만 접근합니다(drive.file 권한). 그 외의 Google 드라이브 파일은 읽거나 수정하지 않습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 처리 위탁

번역, 음성 인식, 보고서 정리를 위해 메시지 내용이 OpenAI API로 전송되어 처리됩니다.

6. 보관과 삭제

보고 데이터는 회사 구글 시트와 드라이브에 회사 업무 기록으로 보관됩니다. 서버 오류 기록은 30일 후 자동 삭제됩니다. 삭제를 원하시면 아래 연락처로 요청해 주세요.

Privacy Policy

LUMORA Sales Bot · Effective 2026-10-09

1. Scope

LUMORA Sales Bot (the "Bot") is an internal Telegram bot used only by LUMORA staff and management.

2. Information processed

  • Messages in designated company group chats (for translation) and private chats with the Bot
  • Daily reports, meeting notes, voice messages and photos submitted by staff
  • Telegram user IDs and names

3. Purpose

Used only for in-team translation, organizing and storing work reports, and work reminders. Never used for advertising, sold, or shared with third parties.

4. Google user data

The Bot accesses only files it created itself (the report Google Sheet and the meeting photo folder) in the company owner's Google account, using the drive.file scope. It does not read or modify any other Google Drive files. The Bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Processors

Message content is sent to the OpenAI API for translation, speech recognition and report summarization.

6. Retention and deletion

Report data is kept in the company's Google Sheet and Drive as business records. Server error logs are deleted automatically after 30 days. To request deletion, contact us below.
